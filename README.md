# Yuh Scanner · versões

Aqui ficam só as versões prontas do **Yuh Scanner**, um app para Windows que digitaliza em multifuncionais com digitalização pela rede (eSCL/AirScan), como a Epson L6160/L6170.

## Baixar

Vá em **[Releases → última versão](../../releases/latest)** e baixe o **`YuhScanner.exe`**.

## Instalar

1. Coloque o `YuhScanner.exe` numa pasta fixa (ex.: `C:\Yuh Scanner`) e crie um atalho na área de trabalho.
2. **Windows 11:** procure **"Controle Inteligente de Aplicativos"** na barra de pesquisa e deixe em **Desligado**. Sem isso o Windows bloqueia o app. O antivírus continua funcionando normalmente.
3. Abra o app com o PC na mesma rede da impressora. Ele encontra o scanner sozinho.

Requisitos: Windows 10 ou 11 (64 bits).

## Atualizações

O app avisa sozinho quando há versão nova. É só clicar em **Atualizar** no canto superior direito.
Cada versão é assinada digitalmente (arquivo `.sig`) e o app recusa qualquer arquivo que não tenha a assinatura oficial.
